# Hosted asides

The repository hosts a small number of pages that are not part of the Post & In
product. They share the site and deployment for convenience.

## Boundary

Post & In's core products are Ice Time, Coach Profiles, and Gear Exchange.
Hosted asides must not be presented as additional Post & In products, roadmap
items, or peers in product-status summaries.

Aside changes can still affect the shared Pages release, routing, privacy, or
security. Update shared platform documentation only when a shared boundary
actually changes.

## Privacy

Sharing a repository and hostname does not make aside content private. Direct-link
and `noindex` pages remain public to anyone with the URL. Do not add player travel
details, contact information, medical information, room assignments, private
academic records, credentials, or other sensitive personal data.
