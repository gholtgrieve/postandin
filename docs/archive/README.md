# Documentation archive

Everything below this directory is **historical**. These files preserve design
context and superseded implementation records. They are
not current setup, deployment, or product instructions.

Use the [documentation index](../README.md) for current guidance. Verify every
historical claim against code and checked-in configuration before relying on it.

Git history remains the authoritative record of individual commits and changes;
the archive should retain only context that is useful beyond a commit diff.
